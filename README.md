# Microservo-com-Potenci-metro
## Atividade 2
Nome: Piettra Nicole Cidral
Professora: Amanda
Descrição:
Nesta atividade, montamos um circuito no Tinkercad usando um Arduino, um potenciômetro e um microservo. O potenciômetro funciona como entrada e, de acordo com a posição dele, o Arduino controla o movimento do microservo. Assim, ao girar o potenciômetro, o servo muda sua posição.
